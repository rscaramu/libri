# Capitolo 1 — Che cos’è un algoritmo

## Prompt 1

Ti descrivo un procedimento a parole: [descrizione]. Dimmi se è un algoritmo in senso stretto verificando una per una le proprietà di finitezza, definitezza ed effettività. Se una proprietà non è rispettata, mostrami un ingresso concreto che lo dimostra.

## Prompt 2

Scrivi in pseudocodice due algoritmi diversi per stabilire se una sequenza contiene un elemento ripetuto. Per ciascuno conta quante operazioni fondamentali esegue nel caso peggiore in funzione di n, e spiega quale sceglieresti per n = 20 e quale per n = 10 milioni, motivando.

## Prompt 3

Ecco una mia funzione che calcola il massimo comune divisore: [codice]. Senza riscriverla, elenca gli ingressi ai margini su cui potrebbe fallire o non terminare (zero, negativi, valori uguali, valori molto grandi) e dimmi per ciascuno che cosa accade.
