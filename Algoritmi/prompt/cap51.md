# Capitolo 51 — NP-completezza

## Prompt 1

## Prompt 2

Il mio problema è una variante di [problema NP-difficile]. Elenca le strade praticabili con le mie dimensioni ([numeri]): ricerca esatta con potatura, programmazione dinamica pseudopolinomiale, formulazione per un risolutore di programmazione intera o di soddisfacibilità, algoritmo di approssimazione, euristica. Per ciascuna indica che garanzia dà e quanto costa.

## Prompt 3

Formula questo problema per un risolutore: [descrizione]. Scrivi le variabili, i vincoli e l’obiettivo in forma di programmazione lineare intera oppure di vincoli logici, e il codice per [OR-Tools o altro risolutore] in [linguaggio]. Indica come verificare in modo indipendente che la soluzione restituita rispetti tutti i vincoli.
