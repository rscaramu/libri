# Manuale completo di Git e GitHub — materiale per i lettori

Materiale di accompagnamento al volume *Manuale completo di Git e GitHub* di Roberto Scaramuzzino.

- `prompt/` — i prompt «Con l'IA» di ogni capitolo (tre per capitolo, con la nota sui limiti), pronti da copiare.
- `esempi/workflow/` — i workflow GitHub Actions, l'azione composite e il `dependabot.yml` dei capitoli 26, 27 e 30.
- `esempi/hook/` — gli hook `pre-commit` e `commit-msg` del capitolo 16.
- `esempi/config/` — la configurazione consigliata dell'Appendice B (`gitconfig`, `gitignore_global`, `gitattributes`).
- `esempi/bisect-test.sh` — lo script usato per `git bisect run` nel capitolo 15.
- `ERRATA.md` — correzioni al testo, se ne verranno segnalate.

Versioni di riferimento: Git 2.43 e successive, GitHub CLI 2.63. Gli esempi del volume sono stati eseguiti nel settembre 2026.
