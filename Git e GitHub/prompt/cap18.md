# Capitolo 18 — Configurazione avanzata, alias e firma

## Prompt 1 — Alias su misura.

```text
Ecco i dieci comandi git che eseguo piu' spesso, con
le opzioni che uso:
[incollate l'elenco]
Proponi alias brevi e memorizzabili per ciascuno,
indica quelli che convengono come funzioni di shell
con argomenti, e scrivi la sezione [alias] completa
per il mio .gitconfig.
```

## Prompt 2 — Firma dei commit da zero.

```text
Uso macOS e ho gia' una chiave SSH per GitHub. Guidami
nella configurazione della firma SSH dei commit, con
i comandi git config, la creazione del file
allowed_signers, il caricamento su GitHub come Signing
key e la verifica che il distintivo Verified compaia.
```

## Prompt 3 — Rivedere la mia configurazione.

```text
Ecco il mio ~/.gitconfig completo:
[incollate il file]
Segnala impostazioni obsolete, ridondanti o rischiose,
suggerisci quelle moderne che mancano (con motivazione)
e riscrivi il file ordinato per sezioni.
```

## I limiti

Non incollate mai chiavi private o passphrase in un assistente. Le istruzioni sulla firma variano con la versione di Git e di GPG: se un comando suggerito non funziona, `git --version` e `gpg --version` sono la prima cosa da comunicare.
