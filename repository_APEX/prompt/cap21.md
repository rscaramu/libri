# Capitolo 21 — Il gestore dei trigger

Prompt del paragrafo «Con l’IA».

1. Questa è la mia classe base per i gestori dei trigger: [incollate GestoreTrigger]. Converti il trigger seguente in un trigger di una riga, un gestore che estende la classe base e una classe di servizio con metodi statici che lavorano in blocco: [incollate il trigger].

2. Aggiungi alla mia classe base GestoreTrigger un contatore statico che registri, per ogni gestore, quante volte è stato eseguito nella transazione, e un metodo per leggerlo. Mantieni invariati i metodi esistenti.

3. Esamina questo gestore Apex e dimmi quali parti sono smistamento, quali filtro sui record cambiati e quali logica di dominio che andrebbe spostata in una classe di servizio: [incollate il gestore].
