# Capitolo 34 — Strumenti e distribuzione

Prompt del paragrafo «Con l’IA».

1. Scrivi una procedura GitHub Actions per un progetto Salesforce DX che, a ogni pull request verso main, crei una scratch org, distribuisca il progetto, esegua tutti i test Apex con copertura, pubblichi l’esito e cancelli la org anche in caso di errore. L’autenticazione al Dev Hub deve usare un segreto.

2. Questo è l’esito di una distribuzione Salesforce fallita: [incollate il messaggio di errore]. Spiegami la causa di ciascun errore, in quale ordine risolverli e quali componenti mancano dalla distribuzione.

3. Questo è il rapporto di Salesforce Code Analyzer sul mio progetto: [incollate il rapporto]. Raggruppa le violazioni per tipo, dimmi quali sono rischi reali di sicurezza o di superamento dei limiti e quali sono solo questioni di stile, e proponi un ordine di intervento.
